# ExcelBan (C#/.NET 8, WinForms)

بازنویسی کامل نسخه قبلی از اول به صورت یک برنامه دسکتاپ ویندوزی با C#.

## پیش‌نیاز
- .NET 8 SDK (https://dotnet.microsoft.com/download)
- ویژوال استودیو ۲۰۲۲ (اختیاری، برای دیباگ راحت‌تر) یا فقط `dotnet` CLI

## اجرا در حالت توسعه
```
cd ExcelBan
dotnet restore
dotnet run
```
اولین بار که `dotnet restore` را اجرا کنید، پکیج‌های ClosedXML و
System.Text.Encoding.CodePages از NuGet دانلود می‌شوند (نیاز به اینترنت دارد).

اگر نسخه دقیق پکیج‌های داخل `ExcelBan.csproj` روی سیستم شما در
NuGet پیدا نشد (ممکن است نسخه‌های جدیدتری منتشر شده باشند)، کافیست از
Visual Studio → NuGet Package Manager → "Update to latest stable" استفاده
کنید یا شماره نسخه را در فایل csproj حذف/به‌روزرسانی کنید.

## انتشار (Publish) به exe

### حالت ۱ - کوچک‌ترین حجم ممکن (framework-dependent)
فرض بر این است که .NET 8 Desktop Runtime روی سیستم مقصد نصب است
یا نصب می‌شود (نصب‌کننده کوچک و رایگان مایکروسافت). خروجی چند مگابایت است:
```
dotnet publish -c Release -r win-x64 --no-self-contained -p:PublishSingleFile=true
```

### حالت ۲ - کاملاً مستقل (self-contained)، بدون نیاز به نصب Runtime روی سیستم مقصد
خروجی بزرگ‌تر (معمولاً ۶۰-۱۰۰+ مگابایت به خاطر باندل شدن کل .NET runtime):
```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

خروجی نهایی در مسیر مشابه زیر قرار می‌گیرد:
```
bin\Release\net8.0-windows\win-x64\publish\ExcelBan.exe
```

## نکات فنی مهم
- انکودینگ خروجی صراحتاً `windows-1256` است و به تنظیمات Regional سیستم
  کاربر وابسته نیست (چون کدپیج به‌صورت دستی مشخص شده، نه گرفته‌شده از
  سیستم). حروف اختصاصی فارسی پ چ ژ گ در این codepage موجودند؛ فقط «ی» و
  «ک» فارسی به معادل عربی‌شان (ي، ك) تبدیل می‌شوند و هر نویسه غیرقابل‌تبدیل
  باقی‌مانده با `?` جایگزین و تعدادش به کاربر گزارش می‌شود.
- تبدیل تاریخ شمسی داخلی و بدون وابستگی خارجی پیاده‌سازی شده
  (`JalaliDate.cs`).
- برای خواندن اکسل از ClosedXML (متن‌باز، MIT) استفاده شده، نه EPPlus (که
  مجوز تجاری‌اش برای استفاده تجاری هزینه دارد) و نه pandas معادل‌های سنگین.
- مقادیر `ContentHeight` روی هر `CollapsiblePanel` در `MainForm.cs`
  تخمینی هستند؛ اگر بعد از اجرا دیدید محتوای یک بخش کمی جا نمی‌شود یا
  فضای اضافه دارد، همین یک عدد را در `BuildLayout()` تغییر دهید.
- مشخصات نمایش داده‌شده در پنجره «درباره برنامه» در بالای فایل
  `AboutForm.cs` به‌صورت ثابت (const) قرار دارد و به‌راحتی قابل ویرایش است.
- فونت فارسی رابط کاربری «وزیرمتن» (Vazirmatn) است و فایل‌های Regular و Bold آن
  در پوشه `Fonts` قرار دارند و به‌صورت `EmbeddedResource` داخل exe جاسازی شده‌اند؛
  بنابراین روی سیستم‌هایی که فونت فارسی نصب ندارند هم درست نمایش داده می‌شود.
  مدیریت فونت در `AppFont.cs` متمرکز است (در صورت شکست بارگذاری، از فونت نصب‌شده
  سیستم و در نهایت Tahoma استفاده می‌کند) و مجوز فونت Vazirmatn OFL است.


## rtlmessagebox (RtlMessageDialog)
این کتابخانه برای نمایش پیام‌های راهنما با پشتیبانی از RTL (راست‌چین) و فارسی استفاده شده است. کد اصلی این کتابخانه از مخزن [Abulhallaj/RtlMessageDialog](https://github.com/Abulhallaj/RtlMessageDialog) گرفته شده و به صورت یک فایل تک‌خطی (`MessageForm.cs`) داخل پروژه ادغام شده است؛ نیازی به پکیج NuGet ندارد.

### ویژگی‌ها
- **راست‌چین RTL**: متن پیام راست‌چین است؛ ترتیب دکمه‌ها نیز mirror شده است.
- **۵نوع پیام**: Info ( آبی), Success (سبز), Warning ( نارنجی ), Error ( قرمز ), Question ( بنفش ) هر کدام رنگ و آیکون خود را دارند.
- **دکمه‌های محلی‌ شده**: متنی دکمه‌های تأیید، انصراف، Yes و No به صورت پیش‌فرض فارسی دارند و قابل تغییر هستند:
  - `MessageForm.OkText` = «تأیید»
  - `MessageForm.CancelText` = «انصراف»
  - `MessageForm.YesText` = «بله»
  - `MessageForm.NoText` = «خیر»
- **جعبه‌ی جزئیات (Details box)**: متن اضافی (مثل `ex.ToString()`) در تنظیمات LTR و چپ‌چین با فونت Monospace نشان داده می‌شود تا مسیرهای Latin و علائم خطا به درستی نمایش داده شوند.
- **کپی با Ctrl+C**: کل پیام (و جزئیات) به کلیپ‌بورد کپی می‌شود.
- **صداها**: صدای سیستم متناسب با نوع پیام پخش می‌شود (Error/Warning/Question/Info).
- **امنیت**: فراخوانی از یک thread دیگر به‌طور خودکار به thread رابط کاربری منتقل می‌شود.
- **طراحی بدون حاشیه**: پنجره بدون نوار عنوان است؛ نوار رنگی بالای آن برای جابه‌جایی (drag) پنجره عمل می‌کند.

### تنظیمات سفارشی (در startup برنامه)
می‌توانید پیش‌فرض دکمه‌ها را در فریمورک خود تغییر دهید (این یک بار در آغاز برنامه اجرا می‌شود):
```csharp
MessageForm.OkText = "تأیید";
MessageForm.CancelText = "انصراف";
MessageForm.YesText = "بله";
MessageForm.NoText = "خیر";
// اگر می‌خواهید فونت دیگری (به جای Segoe UI) برای سربرگ استفاده کنید:
MessageForm.FontName = "Vazirmatn";
```
